# SD5913

I studied Product Design during my undergraduate years. In product design, I learned to observe users, find problems, and create solutions through physical products. However, as I started to learn about other design fields, I found that design does not always have to be a physical object. It can also be an interaction, a digital experience, or a system. This made me start thinking about programming. To be honest, programming was not something I decided to learn by myself at first. It is a required part of this course, and my programming knowledge was almost a blank page when I started. However, I decided to take this course seriously and try my best to learn it, because I began to see how programming could be useful for my future as a designer. For me, learning programming is not mainly about becoming a programmer. It is about understanding a new design field and having more control over my ideas.
Coming from Product Design, I am used to thinking about things such as shape, material, structure, and how people use a product. When I started to learn about interactive and digital design, I found that I needed to think about something different. A digital design does not always have a fixed form. Its appearance can change according to the user's actions, and the system can respond in different ways. This means that I need to think not only about what something looks like, but also about what happens when a user interacts with it.
Programming helps me understand this process. For example, instead of only thinking about the final result, I can start thinking about rules and conditions. What happens when the user clicks something? What should happen next? What if the user makes a different choice? These questions are not usually the main focus when I design a physical product, but they become important when I design an interactive experience. In this way, programming gives me a different way to look at design.
AI has changed the situation again. Today, I can describe an idea to an AI and ask it to create code for me. I think this is a useful tool for designers, especially when we are still learning. However, I do not think that this means programming is no longer important. If I do not understand the basic ideas behind the code, I may only be able to accept whatever the AI gives me. I may not know why the code works, why it does not work, or how to change it when the result is different from what I imagined.
With some programming knowledge, the process becomes different. I can ask AI to generate code, but I can also read the code, understand its basic logic, change some parts, and test the result. I do not need to write everything from the beginning by myself. Instead, I can use AI as a tool while still making my own decisions. For me, this is one of the main reasons why programming is still useful in the age of AI.
